# Website Notaris dan PPAT Lalu Daud Nurjadi M.Kn

Website resmi untuk layanan Notaris dan PPAT Lalu Daud Nurjadi M.Kn

## Struktur Project

### Halaman Publik
- Home
- Tentang Notaris
- Layanan
- Tarif
- Artikel
- FAQ
- Kontak
- Login
- Kalkulator Pajak

### Dashboard
1. **Super Admin** - Notaris (Manajemen akta, keuangan, laporan)
2. **Staf** - Input data, monitoring, pembayaran
3. **Klien** - Status pengurusan, upload dokumen, tagihan

## Fitur Utama
- Kalkulator BPHTB
- Kalkulator PPh Final
- Kalkulator AJB
- Kalkulator Biaya Notaris
- Kalkulator Pinjaman Hak Tanggungan

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js/Express (untuk fase kedua)
- Database: PostgreSQL/MongoDB (untuk fase kedua)

## Deploy
Website di-host di GitHub Pages
